# 잇다

교사가 기록할수록 진화하는 개인 AI 교무수첩입니다.

현재 버전은 입력 중심 첫 화면과 더 빠른 기록·요약 탐색을 제공하는 `0.28.0` 시험판입니다.

## 설치해서 실행하기

`out/make/squirrel.windows/x64/IttaSetup-0.28.0.exe`를 실행합니다.

처음 화면에서 다음 중 하나를 선택합니다.

1. `권장 설정으로 시작`: `문서/잇다`에 기록을 저장합니다.
2. `폴더 선택`: 기존 Obsidian 보관함 등 원하는 폴더를 사용합니다.

## 보안 기본값

- 화면에서 Node.js 기능 직접 사용 금지
- Electron `contextIsolation`과 샌드박스 사용
- 허용한 요청만 IPC로 전달
- 외부 창과 임의 페이지 이동 차단
- 앱 권한 요청 기본 거부
- API 키를 저장하는 코드 없음
- API 키를 화면으로 다시 반환하지 않음
- 연결 확인에 교사 기록을 사용하지 않음
- 개인정보 후보가 남은 기록은 AI 정리 요청 전에 차단
- 의미 검색은 교사의 버튼 선택과 전송 확인 뒤에만 실행
- 의미 검색은 최대 100개·기록당 800자·전체 5만 자로 전송 범위 제한
- 검색어 또는 후보 기록에 개인정보 후보가 있으면 의미 검색 요청 차단
- 의미 검색 결과는 전송한 기록 ID만 허용하고 최대 10개로 제한
- 월간 정리는 선택 기록 최대 100개·전체 5만 자로 전송 범위 제한
- 월간 결과는 교사가 수정·채택하기 전까지 저장하지 않음
- 분기 정리는 선택 기록 최대 200개·전체 5만 자로 전송 범위 제한
- 분기 결과는 교사가 수정·채택하기 전까지 저장하지 않음
- 학기 정리는 선택 기록 최대 300개·전체 5만 자로 전송 범위 제한
- 학기 결과는 교사가 수정·채택하기 전까지 저장하지 않음
- 연간 정리는 선택 기록 최대 500개·전체 5만 자로 전송 범위 제한
- 연간 결과는 교사가 수정·채택하기 전까지 저장하지 않음
- 프로젝트 정리는 선택 기록 최대 200개·전체 5만 자로 전송 범위 제한
- 프로젝트 이름·출발 질문, 선택한 비식별 기록과 교사가 고른 교육자료 근거 최대 5개·전체 2만 자만 AI에 전송
- 기록에 남아 있는 개인정보 후보가 발견되면 프로젝트 정리 요청 차단
- 프로젝트 근거 연결은 실제 전송한 교육자료 조각 ID만 허용
- 프로젝트 결과는 교사가 수정·채택하기 전까지 저장하지 않음
- 교육자료 검색은 AI 호출 없이 기기 안에서 먼저 실행
- 교육자료 연결은 교사가 고른 근거 최대 5개·전체 2만 자만 전송
- 교실 기록·질문·선택 근거에 개인정보 후보가 있으면 전송 차단
- AI의 근거 ID는 실제 전송한 조각만 허용하고 허위 ID를 제거
- 교육자료 연결 결과는 교사가 수정·채택하기 전까지 저장하지 않음
- 뉴스에는 교사가 정한 일반 주제 두 개만 보내며 교실 기록·API 키는 전송하지 않음
- 뉴스 확인은 하루 한 번으로 제한하고 실패해도 기록 기능과 분리
- 외부 브라우저는 로컬 캐시에 있는 Google News HTTPS 링크만 열 수 있음
- 각 주요 기능에 실제 데이터 처리 위치와 외부 전송 범위를 함께 표시
- AI 결과를 자동 확정하지 않고 교사의 수정·채택을 요구
- 응답 길이와 항목 수를 제한하고 잘못된 형식은 거부
- API 키를 백업에 포함하지 않음
- 복원 전 백업 무결성과 안전한 상대 경로 검사
- 복원 직전 현재 상태를 별도로 보관하고 기존 Markdown 폴더를 덮어쓰지 않음
